# Ashlands 灰域

Minecraft 1.21.1 / NeoForge 的灰域世界类型模组。

选择「灰域（Ashlands）」世界类型创建世界后，整个世界都会充满辐射：出生点周围的 3×3 共 9 个区块是唯一的安全区，
越过安全区边界就会受到无限时长的辐射影响，辐射无法被任何手段消除。

## 核心机制

### 世界类型
- 新建世界时在「世界类型」中选择 **灰域 / Ashlands**（依赖世界预设 `ashlands:ashlands`）。
- 只有在灰域世界中这些机制才会生效；普通世界里模组完全不干预。

### 安全区与光幕
- 安全区为出生点所在区块及其周围一圈，共 3×3 = 9 个区块，半径可在配置里改（`safeRadiusChunks`）。
- 安全区与外界之间有一道贯穿整个世界高度（从世界最低点到世界最高点）的绿色光幕。
- 光幕用原版世界边境的渲染方式（`forcefield.png` + 加法混合 + 贴图滚动 + 距离淡出），
  并且只出现在「安全区块与非安全区块的交界处」，所以安全区是什么形状，光幕就是什么形状。

### 净化器
- 新增方块 **净化器**（`ashlands:purifier`），在创造模式「功能方块」标签页中，也可以 `/give @s ashlands:purifier`。
- 手持净化器右键，会把**方块所在的这一个区块**变成安全区：该区块内的辐射消失、光幕自动沿着这个区块重画。
- 净化器是**一次性**的：净化成功后这个方块会直接消失，不会掉落物品。
- 转换瞬间方块上方会升起白色光环（`end_rod` 粒子）与一道上升光柱，并播放紫水晶叮咚声与末地传送门框充能音效。
- 已净化的区块保存在存档数据里（`data/ashlands_purified_chunks.dat`），重进世界或重启服务器后依然有效。

### 辐射
越过光幕后立刻获得 **辐射** 效果，时长无限，效果随感染时间每 10 分钟提升一级（最高 3 级）：

- **1 级**：持续消耗饥饿值与饱和度，偶尔扣除半颗心。
- **2 级**：消耗 1 颗心，并大量消耗饥饿值与饱和度。
- **3 级**：立刻清空饥饿值与饱和度，之后食物也无法恢复；每 5 秒扣除 2 颗心。

补充说明：

- 辐射不可通过牛奶、蜂蜜、图腾或任何其他方式消除（`MobEffect#fillEffectCures` 为空）。
- 若效果被强制清除，模组会在下一次检测时自动重新施加。
- 辐射只作用于玩家：除玩家以外的生物不会获得辐射效果，一旦带上（例如被指令或其他模组施加）会被立刻清除。

### 枯死的森林
- 安全区之外**所有区块**中的树叶（`#minecraft:leaves`）都会被移除，只留下没有树叶的树干，
  整个世界只剩出生点周围的 9 个区块（以及被净化器点亮的区块）还有生机。
- 树叶是在区块刚生成完、**还没有发送给客户端之前**就直接写掉的（`ChunkEvent.Load` 内同步处理），
  所以走进新区域时不会看到「树先长着叶子、过一会儿才慢慢消失」的过程。
- 树上的装饰方块会一并清除，让树只剩原木：藤蔓、可可果、积雪层、发光地衣和垂根。
  其中藤蔓和可可果在整块区块内清除，积雪层只清掉压在树叶上的那些，避免抹掉树旁边的地面积雪。

### 强化怪物
- 灰域世界中生成的敌对生物会被强化：生命值 +100%、攻击力 +50%、移动速度 +15%、护甲 +4。

### 伤害类型
- 辐射伤害使用独立伤害类型 `ashlands:radiation`，无视护甲与附魔，死亡提示为「被辐射吞噬了」。

## 配置

配置文件：`config/ashlands-common.toml`

- `safeRadiusChunks`：安全区半径（单位：区块），默认 `1`。`0` = 只有出生点区块，`1` = 3×3 共 9 个区块，
  `2` = 5×5……最大 `16`（33×33）。光幕位置、辐射判定边界、树叶保留范围都以此为准。
- `minutesPerRadiationLevel`：辐射每提升一级所需的分钟数，默认 `10.0`（最高 3 级）。
- `strengthenMonsters`：是否强化灰域世界中的怪物，默认 `true`。
- `stripTreesOutsideSafeZone`：是否移除安全区之外所有区块的树叶和树的装饰，默认 `true`。
- `radiationDamage`：辐射是否造成伤害，默认 `true`（关闭后只影响饥饿值与饱和度）。

修改后需要重进世界（或重启服务器）才会生效；启动时日志会打印一行
`Ashlands safe zone: radius N chunk(s) = (2N+1)x(2N+1) chunks, centered on chunk (x, z)`，
可以据此确认配置是否已生效。已经生成过的区块里被移除的树叶不会因为调大安全区而恢复。

## 构建

```bash
./gradlew build
```

产物位于 `build/libs/ashlands-1.0.0-mc1.21.1-neoforge.jar`。

## 开发环境运行

```bash
./gradlew runServer   # 开发服务器，run/server.properties 中已设置 level-type=ashlands:ashlands
./gradlew runClient
```
